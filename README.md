# Consulta Migratoria México

Biblioteca profesional de consulta de trámites migratorios y lista de honorarios.
Aplicación web progresiva (PWA) independiente. Datos en Firebase (plan gratuito Spark).

- `public/` — la aplicación que se publica (GitHub Pages).
- `firestore.rules` — reglas de seguridad de la base de datos (se copian en la consola de Firebase).
- `tests/` — pruebas locales con datos ficticios; no se publican.

La aplicación no almacena datos de clientes.
